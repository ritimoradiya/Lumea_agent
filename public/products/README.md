# Product photography

Drop images here named after the product id, e.g. `quench-serum.jpg`.

The renderer uses a photo when one exists for that id and falls back to the
drawn SVG otherwise, so they can be added one at a time without breaking
anything.

Ids come from `config/companies/lumea.json`:

    dissolve-balm      clarity-cleanser   dawn-vitamin-c
    even-niacinamide   smooth-pha         renew-retinol
    quench-serum       shield-cream       recover-night
    bright-eye         daylight-spf       veil-tinted-spf

Aim for 4:5 (e.g. 1000×1250) on a warm off-white backdrop, so they sit with
the rest of the palette.
